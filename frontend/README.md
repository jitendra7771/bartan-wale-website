This folder contains the complete source code for the Bartan Wale frontend application.

Key files and folders:
- `package.json`: Project dependencies and scripts.
- `src/`: Contains all the React source code.
- `index.html`: Main HTML file.
- `vite.config.js`: Vite build configuration.

To run this project locally:
1. Navigate to this directory in your terminal.
2. Run `pnpm install` (or `npm install` / `yarn install`).
3. Run `pnpm dev` (or `npm run dev` / `yarn dev`).
